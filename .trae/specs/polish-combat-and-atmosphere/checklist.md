# Checklist

- [ ] 锯齿巨剑在待机/移动时可见并随朝向翻转，挥砍时按前摇/判定/后摇三阶段摆动
- [ ] 挥砍判定帧出现弧形渐隐拖尾；弹反成功时弧光变亮白并延长
- [ ] 玩家地面移动播放 walk1/walk2 循环（~8fps），空中 jump 帧，死亡 hurt 帧
- [ ] 余烬粒子、落地/冲刺尘土、腐液气泡、受击火花、死亡锈屑全部生效
- [ ] 所有粒子/震动/视觉特效在 headless 下不创建节点、不改逻辑
- [ ] 命中/受击/弹反/死亡触发对应强度的屏幕震动，随后相机回到平滑跟随
- [ ] 敌人受击白闪 ~80ms；Spitter 蓄力有可读预告
- [ ] Level01 有两层视差背景（机械剪影 + 铁梁/橙灯），随相机差速滚动
- [ ] 毒素 ≥80% 时毒素条与标签脉冲；生命 ≤1 时出现红色暗角并随恢复淡出
- [ ] `tests/run_tests.tscn` headless 全绿（exit code 0）
- [ ] 游戏数值与判定逻辑（伤害、判定帧、毒素速率等）零改动
- [ ] 网络下载素材均为 CC0/MIT 等可商用许可，来源已记录
